## 6. 验收口径（DoD）

一项任务只有同时满足以下条件才算完成：

1. 线上真实可访问，不是本地截图；
2. 有对应截图或命令输出，文件名能对应记录单编号；
3. 换人按文档能复现，不依赖某台电脑的临时配置；
4. 真实密钥、密码、AppSecret 没有进入 Git；
5. 两人都 review 过，并在记录单签字。
