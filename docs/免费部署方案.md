# 免费部署方案（无云服务器 / 无域名时的备选）

> 制定日期：2026-11-25
> 适用情况：目前没有云服务器、没有备案域名、小程序只有测试号，但有 GitHub 仓库和一台可上网的电脑。
> 原则：能真实上线多少就记录多少；平台子域名、未备案、测试号这些限制必须如实写进上线记录单。

## 1. 能做到什么、做不到什么

| 作业三要求 | 免费方案能否完成 | 说明 |
|---|---|---|
| 后端部署到云 | ✅ 可以 | Render 免费 Web Service，Docker 部署，HTTPS 平台子域名 |
| MySQL 部署到云 | ✅ 可以 | Aiven / TiDB Cloud 免费 MySQL，TLS 连接 |
| 管理后台发布 + `/api` | ✅ 可以 | Cloudflare Pages 免费静态托管，构建时指定 API 地址 |
| 刷新子路由不 404 | ✅ 可以 | 仓库已加 `frontend/admin/public/_redirects` |
| 对象存储 | ✅ 可以（需注册） | Backblaze B2 / Cloudflare R2 免费额度，S3 兼容驱动已实现 |
| 备案域名 + HTTPS | ❌ 不能 | 免费平台只给 `*.onrender.com`、`*.pages.dev` 子域名，不是自己的备案域名 |
| 小程序体验版 + 非成员扫码 | ⚠️ 条件性 | 测试号不能上传体验版；正式 AppID 免费注册，但 request 合法域名必须已备案 HTTPS 域名 |

**结论：** 免费方案可以把“后端 + 数据库 + 管理后台”真实跑到公网，拿到可访问的 HTTPS 地址和三角色登录；但“备案域名”和“小程序体验版”在没有域名/正式 AppID 的前提下无法合规完成，不能勾选，也不能用本地截图冒充。

## 2. 推荐组合

```
微信开发者工具（游客/测试号，仅本地演示）
        │
        ▼
Cloudflare Pages  ──HTTPS──▶  Render Web Service (Docker, Node)
 zhiyue.pages.dev              zhiyue-api.onrender.com
 管理后台静态文件                 Express /api
        │                              │
        └────────── HTTPS ─────────────┤
                                       ▼
                              Aiven for MySQL（免费）
                              TLS 3306，库 defaultdb
                                       │
                              Backblaze B2 / Cloudflare R2
                              图片对象存储（S3 兼容）
```

仓库已准备好的文件：

- `render.yaml`：Render Blueprint，Docker 构建 `deploy/backend.Dockerfile`，健康检查 `/api/health`
- `deploy/backend.Dockerfile`：Node 24 Alpine 运行后端
- `frontend/admin/public/_redirects`：静态托管 SPA 子路由回退
- `frontend/admin/src/api/index.js`：支持 `VITE_API_BASE` 指向独立 API 域名
- 后端 `DB_SSL=true`：连接云 MySQL 强制 TLS
- 后端 `STORAGE_DRIVER=s3`：切对象存储，无需改代码

## 3. 操作步骤

### 3.1 创建免费云 MySQL（约 15 分钟）

以 **Aiven for MySQL Free** 为例（TiDB Cloud Starter 流程类似）：

1. 注册 Aiven，创建 MySQL 服务，选择 Free 计划，区域选新加坡/东京（离国内较近）。
2. 服务启动后记录：Host、Port、User（通常是 `avnadmin`）、Password、Database（通常是 `defaultdb`）。
3. 下载 CA 证书（`ca.pem`）备用；后端当前用 `rejectUnauthorized: false`，不强制校验证书链，课程演示够用。
4. 在本机导入结构和种子数据（把 `HOST`、`PORT`、`USER` 换成实际值）：

   ```bash
   mysql -h HOST -P PORT -u USER -p --ssl-mode=REQUIRED defaultdb < database/schema.sql
   mysql -h HOST -P PORT -u USER -p --ssl-mode=REQUIRED defaultdb < database/seed.sql
   ```

   也可以用数据库控制台的 SQL 编辑器分别粘贴两个文件的内容。

5. 验证数据量：

   ```sql
   SELECT COUNT(*) AS venues FROM resources WHERE type = 'VENUE';
   SELECT COUNT(*) AS rules FROM resources WHERE open_time IS NOT NULL;
   SELECT COUNT(*) AS bookings FROM bookings;
   ```

   种子数据应为 6 个场地、4 类开放时间 + 2 条维护窗口（合计 6 条时段规则）、14 条预约。

> 免费 MySQL 通常有连接数、存储和休眠限制，以官网当前额度为准。**不要**把免费库当生产库，演示前先导出一份备份。

### 3.2 部署后端到 Render（约 15 分钟）

1. 注册 Render，New → Blueprint，连接 GitHub 仓库 `caikenuan/zhiyue-campus-booking`。
2. Render 读取根目录 `render.yaml`，创建 `zhiyue-api` 服务。首次构建约 3–8 分钟。
3. 在 Environment 里填写 `sync: false` 的变量：

   | 变量 | 值 |
   |---|---|
   | `JWT_SECRET` | 随机 32+ 字符，例如 `openssl rand -base64 36` |
   | `DB_HOST` | Aiven 的 Host |
   | `DB_USER` | Aiven 的 User |
   | `DB_PASSWORD` | Aiven 的 Password |
   | `DB_NAME` | `defaultdb`（或自建库名） |
   | `DB_SSL` | `true` |
   | `STORAGE_PUBLIC_BASE_URL` | `https://<服务名>.onrender.com`（本地驱动时必填，用于拼图片绝对地址） |

4. 部署完成后访问：

   ```bash
   curl https://<服务名>.onrender.com/api/health
   # {"ok":true,"service":"zhiyue-api",...}
   ```

5. 用管理端账号验证 API：

   ```bash
   curl -X POST https://<服务名>.onrender.com/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"account":"admin","password":"admin123"}'
   ```

注意事项：

- Render 免费实例 **15 分钟无请求会休眠**，下次请求冷启动约 30–60 秒。演示前 1 分钟先访问一次 `/api/health` 唤醒。
- 免费实例**没有持久磁盘**，`STORAGE_DRIVER=local` 时上传的图片会随重启丢失。正式演示图片请切 S3（见 3.4），或提前上传并在演示前不重启。
- 平台自动提供 HTTPS，证书由 Render 管理，不需要自己申请。

### 3.3 发布管理后台到 Cloudflare Pages（约 15 分钟）

1. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git，选择同一仓库。
2. 构建配置：
   - Framework preset：`Vite`
   - Root directory：`frontend/admin`
   - Build command：`npm ci && npm run build`
   - Build output directory：`dist`
   - 环境变量：`VITE_API_BASE=https://<服务名>.onrender.com/api`
   - Node 版本：`22`（环境变量 `NODE_VERSION=22`）
3. 部署完成后访问 `https://<项目名>.pages.dev`，用 `admin/admin123` 登录。
4. 验证：
   - 打开 `https://<项目名>.pages.dev/bookings` 后按 F5，页面不 404；
   - Network 里请求地址是 `https://<服务名>.onrender.com/api/...`，状态 200；
   - 浏览器控制台无 CORS 报错（后端已 `app.use(cors())`）。

> 如果 `pages.dev` 在当前网络访问不稳定，可把同一份 `dist/` 用 `npx serve` 或任意静态托管部署；接口地址仍由 `VITE_API_BASE` 决定。也可以在 Render 再建一个 Static Site，构建命令与上面相同。SPA 回退依赖 `_redirects`，Render 静态站点需在 `render.yaml` 里另配 rewrite。

### 3.4 接入免费对象存储（可选，约 20 分钟）

Backblaze B2 免费额度约 10 GB，S3 兼容；Cloudflare R2 也有免费额度（可能需要绑定支付方式）。以 B2 为例：

1. 创建 Bucket（如 `zhiyue-images`），设为 Public。
2. 创建 Application Key，记录 `keyID` / `applicationKey`；Endpoint 形如 `https://s3.us-west-004.backblazeb2.com`。
3. 在 Render 环境变量中修改：

   ```
   STORAGE_DRIVER=s3
   STORAGE_ENDPOINT=https://s3.us-west-004.backblazeb2.com
   STORAGE_REGION=us-west-004
   STORAGE_BUCKET=zhiyue-images
   STORAGE_ACCESS_KEY=<keyID>
   STORAGE_SECRET_KEY=<applicationKey>
   STORAGE_PUBLIC_BASE_URL=https://zhiyue-images.s3.us-west-004.backblazeb2.com
   ```

4. 重新部署后，用管理端“场地管理 → 编辑 → 上传图片”传一张图，复制返回的 URL 到无痕窗口打开，确认 200。
5. 小程序拍照签到同样走该接口，图片 URL 写入 `checkins.photo_url`。

> B2 公共 Bucket 的 URL 可直接访问；如果使用私有 Bucket，需要额外配置公开读或 CDN，课程演示建议先用 Public Bucket。

### 3.5 小程序（当前被阻塞）

- 测试号（测试 AppID）**不能上传体验版**，只能在开发者工具里预览；`wx.uploadFile` / `wx.request` 在真机体验版还要求已备案 HTTPS 域名。
- 免费平台子域名（`onrender.com` / `pages.dev`）不是自己的备案域名，不能加入小程序 request 合法域名。
- 因此本方案**不勾选**“体验版 + 非成员扫码”。可选路径：
  1. 注册一个正式小程序 AppID（个人主体免费），但仍需备案域名才能真机访问线上 API；
  2. 向任课老师说明：功能已在小程序开发者工具用测试号完整跑通，线上后端/后台已真实部署，仅域名备案与体验版受客观条件限制；
  3. 若课程允许，用开发者工具“不校验合法域名”录制真机预览视频作为补充证据（记录单注明是预览，不是体验版）。

## 4. 环境变量总表（Render）

| 变量 | 必填 | 示例 | 说明 |
|---|---|---|---|
| `NODE_ENV` | 是 | `production` | 生产模式 |
| `JWT_SECRET` | 是 | 随机 32+ 字符 | 登录令牌签名，泄露需立刻更换 |
| `DB_HOST` | 是 | `mysql-xxx.aivencloud.com` | 云 MySQL 地址 |
| `DB_PORT` | 是 | `3306` / Aiven 给的端口 | 以控制台为准 |
| `DB_NAME` | 是 | `defaultdb` | 已导入 schema/seed 的库 |
| `DB_USER` | 是 | `avnadmin` | 云数据库账号 |
| `DB_PASSWORD` | 是 | — | 只放平台环境变量，不入库 |
| `DB_SSL` | 是 | `true` | 云 MySQL 基本都要求 TLS |
| `STORAGE_DRIVER` | 是 | `local` / `s3` | 演示图片建议 `s3` |
| `STORAGE_*` | s3 时必填 | 见 3.4 | Bucket、Endpoint、密钥 |
| `STORAGE_PUBLIC_BASE_URL` | local 时必填 | `https://xxx.onrender.com` | 拼接图片绝对地址 |
| `LLM_*` | 否 | — | 不填则 AI 找位走本地规则解析 |

Cloudflare Pages 只需要 `VITE_API_BASE` 和 `NODE_VERSION`。

## 6. 免费额度的坑

| 坑 | 影响 | 规避 |
|---|---|---|
| Render 免费实例休眠 | 首次访问慢 30–60 秒 | 演示前先唤醒；录屏时剪掉等待 |
| 无持久磁盘 | 本地驱动图片重启丢失 | 用 B2/R2，或演示前不重启 |
| 免费数据库休眠/限连接 | 冷启动接口 503 | 演示前先查一次健康检查 |
| 平台子域名非备案域名 | 小程序合法域名配不了 | 如实记录，改用开发者工具预览 |
| 免费额度政策会变 | 步骤中的额度可能过期 | 以各平台官网当前 Free 计划为准 |
| 新加坡节点国内访问慢 | 页面加载数秒 | 提前缓存静态资源；必要时换区域 |

## 7. 记录单怎么写

- 线上地址：填 `https://<admin>.pages.dev`，并注明“平台子域名，未备案”。
- 服务器/数据库：写 Render + Aiven 免费实例，注明区域、休眠策略。
- HTTPS：写“平台自动证书”，不要写“Let's Encrypt 自签”。
- 小程序：写“测试号 + 开发者工具预览，体验版因无正式 AppID 与备案域名未上传”。
- 对象存储：只有真实上传并打开 URL 后才勾选，否则写“本地驱动，云存储未接入”。
- 截图编号与记录单六段一一对应，不拿本地截图代替线上截图。

## 8. 如果后续拿到云服务器

按 `docs/部署文档.md` 的 Docker Compose 方案迁移即可：数据库导出导入、`.env` 换成真实域名、`certbot` 申请证书、Nginx 配置 443。免费方案里的数据可以用 `mysqldump` 迁移，代码不需要改。
